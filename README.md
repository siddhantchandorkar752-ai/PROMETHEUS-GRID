**Prometheus-Grid** is a production-level autonomous energy management system designed for future smart cities. It utilizes **Graph Neural Networks (GNN)** to model energy flow between nodes and **Reinforcement Learning (RL)** to make real-time decisions on energy storage and distribution.

## 🚀 Key Features
- **Neural Core:** Spatial feature extraction using PyTorch Geometric (GNN).
- **RL Agent:** Deep Q-Learning inspired agent for grid stabilization.
- **Vantablack Dashboard:** Luxury Glassmorphism UI for real-time telemetry.
- **Digital Twin:** 24-hour autonomous cycle simulation with zero-latency updates.

## 🛠️ Tech Stack
- **AI/ML:** PyTorch, Torch-Geometric, NumPy.
- **Visualization:** Plotly (Neon Spline Graphics), NetworkX.
- **Infrastructure:** Streamlit (Elite Edition).

## 🎮 Getting Started
1. Clone the repo.
2. Install deps: pip install -r requirements.txt.
3. Launch the Hub: streamlit run app.py.
